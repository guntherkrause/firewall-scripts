IDSeverityCheckBasis

Checks follow Palo Alto Networks' published best practices for security policy: App-ID instead of port-based rules, application-default service, security profiles on every allow rule, logging at session end with forwarding, explicit zones and addresses, and an explicit logged cleanup rule. Shadow detection compares object names only; address and service groups are not expanded, so treat those results as leads to confirm with the firewall's own shadow-rule check at commit time.
